# Offline brand fonts

Instrument Serif Regular and Manrope variable (weights 200–800) are bundled locally.
The original, unmodified files come from Google Fonts:

- https://github.com/google/fonts/tree/main/ofl/instrumentserif
- https://github.com/google/fonts/tree/main/ofl/manrope

Each family is distributed under the SIL Open Font License 1.1; its full copyright
and license are preserved in the adjacent `*-OFL.txt` file. No runtime downloads.
The theme uses Manrope for interface text and InstrumentSerif for editorial titles.
The wordmark is text plus an original vector symbol, not a proprietary typeface.
